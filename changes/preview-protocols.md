### CAN bus, CANopen and PROFIBUS-DP are marked as previews

The CAN bus, CANopen and PROFIBUS-DP connectors are now labelled **preview** in the README and
the documentation. They are tested in CI against simulators (a virtual SocketCAN bus and a
PROFIBUS-DP slave simulator) but not yet on real equipment, so expect rough edges and changes to
their configuration.

If you run one of them on real hardware, please
[tell us how it went](https://github.com/thin-edge/tedge-dot/issues).
