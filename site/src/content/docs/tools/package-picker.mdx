tedge-dot ships as two interchangeable packages that install the same `/usr/bin/tedge-dot`:
**`tedge-dot-c`** (C, the default) and **`tedge-dot-rs`** (Rust, for the few features only it
has). A config, a flow or a cloud integration built against one works unchanged with the other.
Tell the picker about your gateway.

:::caution[Not final yet]
Both packages are maintained and released today, but whether both will remain in the final product is not decided. They implement the same contract, so a config, a flow or a cloud integration built for one carries over to the other.
:::

The picker reads the same data as the package table in the
[install guide](/tedge-dot/get-started/install/), and the full list of differences is the
[parity table](/tedge-dot/reference/sdk/c/#parity-with-the-rust-implementation) of the C
implementation.
