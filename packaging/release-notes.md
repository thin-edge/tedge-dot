Two interchangeable packages, one binary: **`tedge-dot-c`** (C, the default: small, a glibc 2.17
floor, every protocol including the PROFIBUS-DP preview) and **`tedge-dot-rs`** (Rust, for the few features
only it has). Whether both remain in the final product is not decided yet; configs and flows work
with either. Install one of them from the thin-edge.io community repository:

```sh
sudo apt-get install -y tedge-dot-c    # or tedge-dot-rs
```
