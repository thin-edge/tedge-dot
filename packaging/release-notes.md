Two interchangeable packages, one binary: **`tedge-dot-rs`** (Rust, the default) and
**`tedge-dot-c`** (C, for small or old devices: glibc 2.17 floor, adds PROFIBUS-DP). Install one
of them from the thin-edge.io community repository:

```sh
sudo apt-get install -y tedge-dot-rs    # or tedge-dot-c
```
